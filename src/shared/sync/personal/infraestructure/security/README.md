# Cursores de sincronización personal

Bloque implementado y pendiente de validación del usuario. Es una primitiva pura; todavía no acredita listas, pull ni bootstrap funcionales. No usa base de datos ni claves de autenticación. Su referencia es S00 `SYNC.md`, sección «Cursor y bootstrap»; conserva el contrato externo `Cursor` de 32–2048 caracteres URL-safe.

`domain.CursorSigner` ofrece `Issue(binding, position, now)` y `Verify(token, expectedBinding, now)`. La cuenta proviene del actor autenticado; el epoch, del stream consultado en una transacción autorizada. El caller fija el tipo de consulta, sus filtros normalizados con defaults y un nombre versionado del orden estable. No debe copiar ese contexto desde el token. El tamaño de página no forma parte de los filtros semánticos. Las consultas admitidas son pull, autorizaciones, dispositivos, ejercicios, rutinas, workouts y conflictos.

Sync transporta únicamente `Sequence`, string decimal canónica entre 0 y MaxInt64. Las listas transportan una `Key` UTF-8 de 1–512 bytes y un UUID canónico como desempate; si sólo ordenan por UUID, repiten su representación canónica como `Key`. Los repositorios deben usar un comparador fijo y parámetros SQL: ni el orden ni la posición son fragmentos SQL. Una futura lista con más de una clave estable exige ampliar este tipo de forma coordinada.

El formato privado es `pc1.kid.payload.mac`, con payload JSON canónico fijo y HMAC-SHA256 sobre un prefijo de propósito, versión, kid y payload. La cuenta, query, epoch, posición, emisión y caducidad están firmadas; filtros y orden se incluyen como hashes con prefijos distintos. Base64url no cifra: no colocar secretos en posiciones o filtros. No es un JWT ni una credencial. La firma se comprueba antes de interpretar el payload, y cuenta/query/filtros/orden antes de devolver errores de epoch o caducidad. Cualquier error devuelve una posición vacía.

El constructor exige un keyring propio de claves aleatorias de 32 bytes, hasta 32 versiones con nombres ASCII URL-safe de 1–64 caracteres. Copia las claves y oculta el material en representaciones de diagnóstico. La rotación conserva versiones anteriores mientras haya cursores válidos (30 días como mínimo si se emitieron cursores sync con ellas). El constructor no puede detectar si el operador reutilizó material de otra finalidad: la DI debe proporcionar claves independientes.

La vigencia es fija: 30 días para sync y 24 horas para listas. Emisión y caducidad se almacenan en UTC con tres decimales; `now` se normaliza a UTC y al emitir se trunca al milisegundo, acortando como máximo una fracción de milisegundo la vigencia. No hay tolerancia: emisión futura, reloj cero o años fuera de RFC3339 fallan cerrado; en el instante exacto de caducidad el cursor ya no sirve. El payload debe conservar exactamente la duración correspondiente a su consulta. Entradas con propiedades desconocidas/duplicadas, aliases de mayúsculas, formas JSON alternativas o base64 no canónico se rechazan, incluso si su MAC es válido.

`ErrCursorInvalid`, `ErrCursorExpired`, `ErrCursorEpochChanged` y `ErrCursorConfiguration` son sentinels distintos. El caller traduce la ausencia de cursor pull y una secuencia anterior a la compactación a `CURSOR_EXPIRED`/bootstrap; el firmador no consulta el piso durable. Una sesión vigente debe revalidarse dentro de cada transacción antes de leer datos, aunque el cursor sea válido. Cambiar epoch no borra pendientes. Si el escape JSON hace que una clave de posición supere 2048 caracteres al codificar, la emisión falla sin entregar un token inválido.

`tests/mancuerna/cursor_run.py` ejecuta unitarias con race, vet y un vector independiente generado con Python stdlib, registra nombres obligatorios y hashes de las fuentes y falla si encuentra pruebas omitidas. Cubre rotación/retiro de claves, alteraciones, cruce de cuenta/query/filtros/orden/epoch, límites, MaxInt64, TTL exacto, reloj futuro, serialización estricta y expansión por escapes. No requiere red, proveedor ni PostgreSQL; la validación de floor y el recorrido completo pertenecen a la integración futura de sync.
